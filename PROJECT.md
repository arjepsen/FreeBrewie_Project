# Project charter

## Mission

Define a maintainable, efficient, extensible, independently designed replacement for the existing hardware.

## Whole-system monorepo

The eventual workstreams include project governance, evidence, requirements, decisions, milestones, the Linux image, SOM application, MCU firmware, interfaces, UI, system integration, testing, and documentation. These names identify workstreams only and do not claim architectural boundaries.

## Clean-slate definition

All new work is independently derived from current requirements and verified facts. A new decision may reach the same conclusion as earlier work only when fresh evidence, alternatives, and independent reasoning justify it.

## Project-level quality goals

Efficiency, responsiveness, maintainability, extensibility, and verifiability are project-level quality goals. Later milestones will make the relevant goals measurable.

## Out of scope

Until another milestone is approved and active, all implementation, reference
inspection, hardware investigation, and technical product design are out of
scope. This includes Linux technologies or image design, the SOM application,
MCU firmware, communication protocols, brewing logic, UI technology, and
implementation skeletons.
